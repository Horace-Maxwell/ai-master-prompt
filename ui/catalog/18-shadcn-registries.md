# shadcn 官方 Registry 索引（全量）

> 本文件由 `scripts/build.py` 从 `data/registries.json` 自动生成（快照日期 2026-11-09，来源 https://ui.shadcn.com/r/registries.json）。刷新：`python3 scripts/sync_registries.py && python3 scripts/build.py`。

官方索引里的全部 548 个命名空间，合计约 142,978 个可安装条目。这里的任何一个都**无需配置**即可安装：

```bash
npx shadcn@latest list @命名空间                    # 看它有哪些条目
npx shadcn@latest search @命名空间 --query 关键词    # 按关键词找
npx shadcn@latest add @命名空间/条目名               # 安装
```

按官方排名分排序。「本库精选」一列有内容的，在前面的分类目录里有中文说明和注意事项，优先看那些。说明一列是各 registry 作者自己写的英文简介，未经本库核实。
